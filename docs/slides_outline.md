## 4. 피지컬 컴퓨팅이란?
- 도식: 입력(센서) → 처리(라즈베리파이) → 출력(LED)
- 생활 예: 자동문, 스마트 가로등, 체온계

## 5. 라즈베리파이의 역사
- 2009 재단 설립(영국, "학생들이 싸고 쉽게 배우는 컴퓨터") → 2012 Pi 1 (35달러) → 2015 Pi Zero·Astro Pi(ISS) → 2016 Pi 3 → **2019 Pi 4** → 2021 Pico → 2023 Pi 5
- 가로 연표 그림, 수천만 대 판매된 교육용 컴퓨터

## 5-2. Raspberry Pi 4B 제원
- 사진 + 제원 표: 4코어 1.8GHz / 8GB / Wi‑Fi·블루투스 / USB 3.0·2.0 / HDMI 2개 / microSD / USB‑C 5V 3A / **GPIO 40핀**

## 5-3. 가격: 35달러 컴퓨터가 비싸진 이유
- 출시가 1GB 35달러 / 4GB 55달러 / 8GB 75달러 → 2026년 4월 4GB 100달러 / 8GB 165달러
- AI 데이터센터 → 메모리 공장이 고성능 메모리로 → LPDDR4 1년 새 약 7배 (공식 발표)
- 강사: "AI 발전이 교실 컴퓨터 값에도 영향을 줍니다."

## 5-4. 소개 영상 (선택, 2~3분)
- What is a Raspberry Pi? (공식) / What is a Raspberry Pi 4 (공식) / 라즈베리 파이 소개 및 설치 방법 (한국어) — 교재 01의 링크

## 6. Argon One V2 케이스
- 뒤쪽 포트 그림 (전원, HDMI×2), 위쪽 자석 덮개 = GPIO
- 전원 버튼: 짧게 = 켜기, 길게 = 끄기

## 7. SenseHAT 한눈에 보기
- 부품 위치 그림: LED 8×8, 조이스틱, 센서들, 컬러 센서(V2)
- 🎤 "원래 우주정거장에 간 보드입니다(Astro Pi)."

## 8. LED 좌표

## 9. 첫 부팅

## 10. 한글 설정
