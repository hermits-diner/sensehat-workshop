## p01 · 기울이면 화살표 (움직임 센서)

보드를 왼쪽·오른쪽으로 기울이면 그 방향 글자가 나옵니다.

```python
from sense_hat import SenseHat   # SenseHAT 도구 상자 가져오기
sense = SenseHat()               # 내 SenseHAT을 sense라고 부르기
sense.set_rotation(180)          # 화면 180도 돌리기 (케이스에 거꾸로 꽂힘)
sense.clear()                    # 화면 지우기 (켜진 LED 끄기)

while True:
    x = sense.get_accelerometer_raw()["x"]   # 좌우 기울기 (-1 ~ 1)
    if x < -0.3:                 # 오른쪽으로 기울이면 (케이스 때문에 음수)
        sense.show_letter("R")
    elif x > 0.3:                # 왼쪽으로 기울이면
        sense.show_letter("L")
    else:                        # 거의 평평하면
        sense.clear()
```
- `get_accelerometer_raw()["x"]`: 좌우로 얼마나 기울었는지 (-1 ~ 1). Argon 케이스에서는 **오른쪽으로 기울이면 음수(-)** 입니다.
- `elif`: "그게 아니고 만약 ~라면"
- 쓰인 문법: `while`(s10), `if`(s09), 변수(s02)
- 🔁 바꿔 보기: 글자 대신 색으로 표시하기
- ⚠️ SenseHAT이 거꾸로 꽂혀 있어서 센서의 왼쪽·오른쪽도 반대입니다. Scratch 블록의 `right`에 `L`을 넣은 이유입니다.

```scratchblocks
when tilted [right v] :: extension hat // 보드가 거꾸로라 반대
display character [L] :: extension

when tilted [left v] :: extension hat // 보드가 거꾸로라 반대
display character [R] :: extension
```

## p02 · 카멜레온 (컬러 센서, SenseHAT V2 전용)

컬러 센서에 물건을 대면 LED 전체가 그 색으로 바뀝니다.

```python
from sense_hat import SenseHat   # SenseHAT 도구 상자 가져오기
sense = SenseHat()               # 내 SenseHAT을 sense라고 부르기
sense.set_rotation(180)          # 화면 180도 돌리기 (케이스에 거꾸로 꽂힘)
sense.clear()                    # 화면 지우기 (켜진 LED 끄기)
sense.colour.gain = 64           # 컬러 센서 감도 최대로 (1, 4, 16, 64 중)

while True:
    r, g, b, c = sense.colour.colour   # 센서가 본 빨강·초록·파랑·밝기
    sense.clear(r, g, b)               # 그 색으로 화면 채우기
```
- `sense.colour.colour`: 빨강·초록·파랑·밝기 4개 값을 한 번에 줌
- `r, g, b, c = ...`: 4개 값을 변수 4개에 나눠 담기
- `gain = 64`: 센서 감도를 최대로 (1, 4, 16, 64 중 하나만 가능)
- 컬러 센서는 LED 아래쪽 작은 창입니다. 물건을 **가까이** 대 보세요.
- 어두우면 색이 잘 안 나옵니다. 휴대폰 손전등으로 물건을 비추면 선명해집니다.
- 🔁 바꿔 보기: 색 이름 맞히기 (`if r > g and r > b:` → 빨강)
- 💡 Scratch에는 컬러 센서 블록이 없어서 Python으로만 합니다.

## p03 · 전자 주사위 (조이스틱 + 무작위)

조이스틱을 누를 때마다 1~6 중 하나가 나옵니다.

```python
from sense_hat import SenseHat   # SenseHAT 도구 상자 가져오기
from random import randint       # 무작위 수 도구 가져오기
sense = SenseHat()               # 내 SenseHAT을 sense라고 부르기
sense.set_rotation(180)          # 화면 180도 돌리기 (케이스에 거꾸로 꽂힘)
sense.clear()                    # 화면 지우기 (켜진 LED 끄기)

while True:
    e = sense.stick.wait_for_event()            # 조이스틱을 기다리기
    if e.action == "pressed":                   # 누르면
        sense.show_letter(str(randint(1, 6)))   # 1~6 중 아무 수 보여 주기
```
- `randint(1, 6)`: 1~6 중 아무 수 하나 (새 개념: 무작위)
- 쓰인 문법: 조이스틱(s11), `str`(s08)
- 🔁 바꿔 보기: 1~100 뽑기 (`show_message` 사용)

Scratch에서는 **흔들면** 주사위가 나오게 해 봅시다.

```scratchblocks
when shaken :: extension hat
display character (pick random (1) to (6)) :: extension
```

## 센서 이야기: 온도는 왜 높게 나올까? (10분)

1. 방 온도계와 SenseHAT 온도를 비교해 봅니다. → SenseHAT이 5~15℃ 높습니다.
2. 이유: SenseHAT이 라즈베리파이 **CPU 바로 위**에 있어서, CPU 열을 함께 잽니다.
3. 해결 방법 (학생과 토의)
   - 연장 케이블로 SenseHAT을 떨어뜨리기
   - 실제 온도와의 **차이만큼 빼서 보정**하기: `t = sense.get_temperature() - 10`
4. 수업 포인트: **"센서 값을 그대로 믿지 말고, 확인하고 보정한다"** → 과학적 태도

| 학교급 | 추천 활동 | 도구 |
|---|---|---|
| 초등 | LED 픽셀아트 이름표, 흔들면 주사위, 신호등 | Scratch |
| 중학교 (정보) | s05~s11로 순차·반복·조건 익히기, 온도 알리미 | Scratch → Python |
| 고등학교 | 교실 온습도 측정·기록, 센서 보정 실험, 함수로 코드 정리 | Python |

### 수업 팁
- **짝 코딩**: 한 명은 입력, 한 명은 읽어 주기 → 5분마다 교대

- 오류가 나면 **빨간 오류 메시지 마지막 줄**을 같이 읽는 연습
- 수업이 끝나면 `sense.clear()`로 LED 끄기
