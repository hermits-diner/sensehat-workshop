# 2차시 · SenseHAT으로 배우는 파이썬 기초 (50분)

> 규칙: **한 단계 = 새 개념 1개**. 코드를 입력하고 ▶ 실행하고, "바꿔 보기"를 한 가지 해 봅니다.
> 빨리 끝난 분은 ⭐ 도전 과제를 해 봅니다.

## 모든 코드의 첫 네 줄 (항상 똑같음)

```python
from sense_hat import SenseHat   # SenseHAT 도구 상자 가져오기
sense = SenseHat()               # 내 SenseHAT을 sense라고 부르기
sense.set_rotation(180)          # 화면 180도 돌리기 (케이스에 거꾸로 꽂힘)
sense.clear()                    # 화면 지우기 (켜진 LED 끄기)
```

| 줄 | 뜻 |
|---|---|
| `from sense_hat import SenseHat` | SenseHAT 도구 상자를 가져오기 |
| `sense = SenseHat()` | 내 SenseHAT을 `sense`라는 이름으로 부르기 |
| `sense.set_rotation(180)` | 화면을 180도 돌리기 (Argon 케이스에서는 SenseHAT이 거꾸로 꽂히기 때문) |
| `sense.clear()` | 화면 지우기 (이전에 켜져 있던 LED 끄기) |

> 아래 예제에서는 이 네 줄을 생략합니다. 파일마다 맨 위에 꼭 넣어 주세요.
> `sleep`을 쓰는 단계(s05~)는 `from time import sleep`도 함께 넣습니다.

Scratch도 **초록 깃발 바로 아래**에 항상 이 두 블록을 먼저 놓습니다. (아래 예제에서는 생략)

```scratchblocks
when green flag clicked
set rotation to (180 v) degrees :: extension
clear display :: extension
```

| 단계 | 새 개념 | 결과 | 시간 |
|---|---|---|---|
| s01 | 명령(함수 호출) | 글자 흘리기 | 3분 |
| s02 | 변수 | 글자를 변수에 담기 | 3분 |
| s03 | 색(RGB) | 빨간 글자 | 4분 |
| s04 | 좌표 | 점 하나 켜기 | 4분 |
| s05 | 순서·기다리기 | A → B 차례로 | 4분 |
| s06 | 반복(for) | 한 줄 켜기 | 5분 |
| s07 | 리스트 | 무지개 신호등 | 4분 |
| s08 | 센서 읽기 | 온도 표시 | 4분 |
| s09 | 조건(if) | 더우면 빨강 | 4분 |
| s10 | 무한 반복(while) | 계속 재는 온도계 | 4분 |
| s11 | 조이스틱 | 누른 방향 표시 | 5분 |
| s12 | 함수 만들기(def) | 번쩍! | 4분 |

## s01 · 글자 흘리기 — 명령
```python
sense.show_message("Hi")   # 글자 흘려 보여 주기 (글자는 "따옴표" 안에)
```
- `sense.show_message(...)`: "SenseHAT아, 글자를 보여 줘"라는 **명령**
- 글자는 `"따옴표"` 안에 씁니다(문자열).
- 🔁 바꿔 보기: `"Hi"` 대신 내 이름(영문)

```scratchblocks
when green flag clicked
display text [Hi] :: extension
```

## s02 · 변수 — 이름표 붙인 상자
```python
name = "Kim"               # name 상자에 "Kim" 담기
sense.show_message(name)   # 상자 속 글자 보여 주기 (따옴표 없음!)
```
- `name`이라는 상자에 `"Kim"`을 넣고, 상자를 통째로 넘깁니다.
- 🔁 바꿔 보기: `name`에 다른 이름 넣기

```scratchblocks
when green flag clicked
set [name v] to [Kim]
display text (name) :: extension
```

## s03 · 색 — 빨강·초록·파랑 섞기
```python
# text_colour=(빨강, 초록, 파랑) → 각각 0~255
sense.show_message("Hi", text_colour=(255, 0, 0))
```
- `(빨강, 초록, 파랑)`: 각각 0~255
- `(255, 0, 0)` 빨강, `(0, 255, 0)` 초록, `(255, 255, 0)` 노랑
- 🔁 바꿔 보기: 보라색 만들기
- ⭐ 도전: `scroll_speed=0.05`를 추가해서 속도 바꾸기

```scratchblocks
when green flag clicked
set colour to [#ff0000] :: extension
display text [Hi] :: extension
```

## s04 · 좌표 — 점 하나 켜기
```python
# set_pixel(x, y, 색): x는 가로 0~7, y는 세로 0~7
sense.set_pixel(0, 0, (0, 255, 0))   # 왼쪽 위 첫 칸을 초록으로
```
- `set_pixel(x, y, 색)`: 왼쪽 위가 `(0, 0)`, 오른쪽 아래가 `(7, 7)`
- 🔁 바꿔 보기: 네 모서리에 점 찍기

```scratchblocks
when green flag clicked
set pixel x (0 v) y (0 v) to [#00ff00] :: extension
```

## s05 · 순서와 기다리기
```python
from time import sleep           # 기다리기(sleep) 도구 가져오기
sense.show_letter("A")     # 글자 한 개 보여 주기
sleep(1)                   # 1초 기다리기
sense.show_letter("B")
sleep(1)
sense.clear()              # 화면 끄기
```
- 컴퓨터는 **위에서 아래로 한 줄씩** 실행합니다.
- `sleep(1)`: 1초 기다리기
- 🔁 바꿔 보기: 3, 2, 1 카운트다운

```scratchblocks
when green flag clicked
display character [A] :: extension
wait (1) seconds
display character [B] :: extension
wait (1) seconds
clear display :: extension
```

## s06 · 반복(for) — 같은 일을 여러 번
```python
from time import sleep           # 기다리기(sleep) 도구 가져오기
for x in range(8):                       # x = 0, 1, 2, … 7 차례로
    sense.set_pixel(x, 0, (255, 0, 0))   # 맨 윗줄 x번째 칸 켜기 (들여쓰기 4칸)
    sleep(0.2)
```
- `range(8)`: 0, 1, 2, …, 7
- 반복할 줄은 **들여쓰기(스페이스 4칸)** 합니다.
- 🔁 바꿔 보기: 맨 아래 줄(`y = 7`)을 켜기
- ⭐ 도전: 세로줄 켜기

```scratchblocks
when green flag clicked
set [x v] to [0]
repeat (8)
  set pixel x (x) y (0 v) to [#ff0000] :: extension
  wait (0.2) seconds
  change [x v] by (1)
end
```

## s07 · 리스트 — 여러 개를 한 줄로
```python
from time import sleep           # 기다리기(sleep) 도구 가져오기
colors = [(255, 0, 0), (255, 255, 0), (0, 255, 0)]   # 빨강, 노랑, 초록
for c in colors:     # 리스트에서 하나씩 꺼내 c에 담기
    sense.clear(c)   # 화면 전체를 c 색으로 채우기
    sleep(1)
```
- `[ ... ]` 대괄호 안에 여러 값을 **순서대로** 담은 것이 리스트
- `for c in colors`: 리스트에서 하나씩 꺼내 `c`에 넣기
- `sense.clear(색)`: 화면 전체를 그 색으로 채우기 (Scratch는 `set background to` 블록)
- 🔁 바꿔 보기: 리스트에 파란색 추가

```scratchblocks
when green flag clicked
delete all of [colors v]
add [#ff0000] to [colors v]
add [#ffff00] to [colors v]
add [#00ff00] to [colors v]
set [i v] to [1]
repeat (length of [colors v])
  set background to (item (i) of [colors v]) :: extension
  wait (1) seconds
  change [i v] by (1)
end
```

## s08 · 센서 읽기 — 온도
```python
t = sense.get_temperature()         # 온도(℃)를 읽어 t에 담기
sense.show_message(str(round(t)))   # 반올림 → 글자로 바꿔(str) 보여 주기
```
- `get_temperature()`: 온도를 **숫자**로 알려 줌 (예: 27.8341…)
- `round(t)`: 반올림 → `28`
- `str(...)`: 숫자를 **글자**로 바꿈 (`show_message`는 글자만 받음)
- 🔁 바꿔 보기: `get_humidity()`로 습도 표시
- 💡 온도가 실제보다 높게 나오나요? → 3차시에서 이유를 알아봅니다.

```scratchblocks
when green flag clicked
display text (round (temperature :: extension)) :: extension
```

## s09 · 조건(if) — 만약 ~라면
```python
t = sense.get_temperature()
if t > 30:                  # 30℃보다 높으면 (줄 끝에 : 꼭)
    sense.clear(255, 0, 0)  # 빨강
else:                       # 그렇지 않으면
    sense.clear(0, 0, 255)  # 파랑
```
- 30도보다 높으면 빨강, 아니면 파랑
- `if` 줄 끝의 `:`(콜론)과 들여쓰기를 잊지 마세요.
- 🔁 바꿔 보기: 손으로 센서를 감싸서 색이 바뀌는 기준을 찾아보기

```scratchblocks
when green flag clicked
if <(temperature :: extension) > (30)> then
  set background to [#ff0000] :: extension
else
  set background to [#0000ff] :: extension
end
```

## s10 · 무한 반복(while) — 계속 재기
```python
from time import sleep           # 기다리기(sleep) 도구 가져오기
while True:                             # 멈출 때까지 계속 반복 (정지: ■ 버튼)
    t = sense.get_temperature()
    sense.show_message(str(round(t)))
    sleep(1)                            # 1초 쉬고 다시 재기
```
- `while True:`: 멈출 때까지 **계속** 반복
- 멈추기: Thonny의 **Stop(■)** 버튼
- 🔁 바꿔 보기: s09의 `if`를 넣어 온도에 따라 글자색 바꾸기

```scratchblocks
when green flag clicked
forever
  display text (round (temperature :: extension)) :: extension
  wait (1) seconds
end
```

## s11 · 조이스틱 — 누르면 반응
```python
while True:
    e = sense.stick.wait_for_event()      # 조이스틱을 움직일 때까지 기다리기
    if e.action == "pressed":             # 눌렀을 때만 (뗄 때는 무시)
        sense.show_message(e.direction)   # 누른 방향(up/down/left/right) 보여 주기
```
- `wait_for_event()`: 조이스틱을 움직일 때까지 기다림
- `e.direction`: `up`, `down`, `left`, `right`, `middle`
- `==`: "같은가?" (`=` 하나는 "넣기"이니 구분하세요)
- 🔁 바꿔 보기: 방향 대신 `show_letter("U")` 같은 글자 한 개
- ⚠️ 위로 밀었는데 `down`이 나오나요? SenseHAT이 **거꾸로 꽂혀** 있어서 조이스틱 방향이 반대로 읽힙니다.
  (`set_rotation(180)`은 화면만 돌리고 조이스틱은 돌리지 않음. Scratch도 같음) 가운데 누르기(`middle`)는 그대로입니다.

```scratchblocks
when joystick pushed [up v] :: extension hat
display text [up] :: extension

when joystick pushed [down v] :: extension hat
display text [down] :: extension
```

## s12 · 함수 만들기(def) — 나만의 명령
```python
from time import sleep           # 기다리기(sleep) 도구 가져오기
def flash(color):        # flash라는 새 명령 만들기 (color는 받을 값)
    sense.clear(color)   # 받은 색으로 켜고
    sleep(0.5)
    sense.clear()        # 끄기

flash((255, 0, 0))       # 새 명령 쓰기: 빨강 번쩍
flash((0, 0, 255))       # 파랑 번쩍
```
- `def 이름(재료):` 여러 줄을 묶어 **새 명령**을 만듭니다.
- 한 번 만들면 `flash(...)`처럼 몇 번이고 불러 씁니다.
- 🔁 바꿔 보기: 경찰차처럼 빨강·파랑 번갈아 5번 (`for` 사용)

```scratchblocks
define flash (color)
set background to (color) :: extension
wait (0.5) seconds
set background to [#000000] :: extension

when green flag clicked
flash [#ff0000] :: custom
flash [#0000ff] :: custom
```

## 정리: 오늘 배운 문법

| 문법 | 한 줄 요약 | 단계 |
|---|---|---|
| `명령(...)` | 일 시키기 | s01 |
| `이름 = 값` | 변수에 담기 | s02 |
| `(R, G, B)` | 색 표현 | s03 |
| `for ... in range()` | 정해진 횟수만큼 반복 | s06 |
| `[a, b, c]` | 리스트 | s07 |
| `str()`, `round()` | 글자로 바꾸기, 반올림 | s08 |
| `if / else` | 조건 | s09 |
| `while True` | 무한 반복 | s10 |
| `def` | 함수 만들기 | s12 |
