# 라즈베리파이와 SenseHAT으로 배우는 피지컬 컴퓨팅

> 초·중·고 교사 연수 · 3차시(50분 × 3 = 150분 연강)
> 강사: **오정훈** (부산동고등학교)

## 1. 연수 목표
1. 라즈베리파이에 운영체제를 직접 설치하고, 한글 환경을 설정할 수 있다.
2. SenseHAT의 LED·조이스틱·센서를 Python과 Scratch로 제어할 수 있다.
3. 변수·반복·조건 같은 파이썬 기초 문법을 한 번에 하나씩, 짧은 코드와 "눈에 보이는 결과"로 익힌다.
4. 배운 내용을 자기 학교급 수업에 적용할 아이디어를 얻는다.

## 2. 시간표

| 차시 | 시간 | 주제 | 주요 활동 |
|---|---|---|---|
| 1차시 | 0~50분 | 시작하기 | SD카드 굽기, 라즈베리파이·SenseHAT 소개, 한글 환경 설정, 첫 코드 |
| 2차시 | 50~100분 | SenseHAT으로 배우는 파이썬 기초 | 12개 작은 단계(s01~s12), 단계마다 개념 1개·코드 1~6줄, Python ↔ Scratch 비교 |
| 3차시 | 100~150분 | 미니 프로젝트와 수업 적용 | 쉬운 프로젝트 택1(p01~p03), 학교급별 적용, 정리 |

> 150분 연강이라 휴식 시간이 따로 없습니다. SD카드를 굽는 시간(1차시)과 프로젝트 시간(3차시)에 자유롭게 쉬도록 안내합니다.

## 3. 준비물 (1~2인 1세트)

| 품목 | 비고 |
|---|---|
| Raspberry Pi 4B (8GB) | |
| Argon One V2 케이스 | 상단 GPIO 커버를 열고 SenseHAT을 장착 |
| Sense HAT (V2) | V2에는 컬러 센서가 있음. V1이면 컬러 센서 프로젝트(p02) 제외 |
| microSD 카드 32GB 이상 + 카드 리더기 | 참가자 노트북/PC에서 굽기 |
| USB-C 전원 어댑터 (5V 3A) | 전원이 약하면 번개 모양 경고가 뜸 |
| 모니터 + **일반(표준) HDMI 케이블** | Argon One V2는 HDMI가 뒤쪽 풀사이즈 포트로 나와서 micro-HDMI 케이블이 필요 없음 |
| 키보드·마우스 | 한/영 키가 있는 한글 키보드 권장 |
| 참가자 PC (Windows/macOS) | Raspberry Pi Imager 미리 설치 |

## 4. 강사 사전 체크리스트
- [ ] 연수장 Wi‑Fi `SWAI_5G` / `swai2024`가 켜져 있는지 확인하고 칠판에도 적기 (5GHz라 공유기와 너무 멀면 약할 수 있음)
- [ ] **Raspberry Pi OS Full (64-bit)** 이미지 파일(`.img.xz`)을 미리 받아 USB 메모리 여러 개에 복사
  - 파일: `2026-09-15-raspios-trixie-arm64-full.img.xz` (약 2GB)
  - 직접 받기: https://downloads.raspberrypi.com/raspios_full_arm64/images/raspios_full_arm64-2026-09-15/2026-09-15-raspios-trixie-arm64-full.img.xz  - 참가자 PC가 각자 인터넷으로 받으면 Wi‑Fi가 느려져 시간이 크게 늘어납니다
- [ ] **예비 SD카드**를 참가자 수의 20% 이상 미리 구워 두기 (굽기 실패·시간 부족 대비)
- [ ] 예비 SD카드에는 한글 폰트·입력기 설치, 한국어 화면 설정, 입력기에 한글 추가까지 해 두기
- [ ] 참가자 PC에 Raspberry Pi Imager 설치 안내 메일 발송 (https://www.raspberrypi.com/software/)
- [ ] 실습 예제 폴더(`code/`)를 USB 메모리 또는 공유 링크로 준비
- [ ] SenseHAT 장착 상태 점검: 부팅 시 LED에 무지개가 잠깐 켜졌다 꺼지면 정상
- [ ] 강사 기기로 전체 예제 한 번씩 실행해 보기

## 5. 자주 생기는 문제와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 부팅 시 무지개 LED가 안 켜짐 | SenseHAT 핀이 한 칸 밀림 | 전원을 끄고 40핀 전체가 맞게 꽂혔는지 확인 |
| `OSError` / SenseHAT을 못 찾음 | HAT 인식 실패 | 재부팅, 핀 접촉 확인 |
| 온도가 실제보다 10℃ 이상 높음 | CPU 열이 센서에 전달됨 | 정상 현상. 3차시 "센서 보정"에서 다룸 |
| 메뉴·화면이 영어로 나옴 | Imager의 Seoul 설정은 시간대·키보드만 바꿈 | Preferences → Control Centre → Localisation → Set Locale에서 ko (Korean) 선택 후 재부팅 |
| 한글 입력이 안 됨 | 입력기에 한글을 추가하지 않음 | 키보드 아이콘 오른쪽 클릭 → 설정 → **한글** 추가 → 적용. 한/영 키가 안 되면 `Ctrl + Space` |
| LED에 한글이 안 나옴 | `show_message`는 영문·숫자만 지원 | 영문으로 쓰거나 픽셀로 직접 그림 |
| 화면이 안 나옴 | HDMI 포트 문제 | 케이스 뒤쪽의 다른 HDMI 포트에 꽂고 재부팅 |
